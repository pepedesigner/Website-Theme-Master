Caching

Cache reads, passed through 1:1.

On the flagship model, a cache read costs 0.0318× the input price — about $0.0140 per million tokens. We pass that discount through untouched.

What it does not do

Caching does not raise our margin — the platform takes the same cut either way. It changes how much work one dollar of quota buys, which is why a $70 pool buys around $196 of list-price work.

Measured, not assumed

The 2.8× figure is quoted at an 80% cache hit rate with the output around 7% of the input tokens. We quote the conservative end — heavier input means a bigger multiple.

Method

How a model earns its badge.

Continuous evaluation

SWE-bench and HumanEval runs on the same hardware every day, scored on real agent traces rather than chat prompts.

Tool-calling repair

Malformed JSON arguments and dropped thinking tags are repaired at the gateway, so a weak model still behaves like a stable one.

Provider tuning

Delivery is pinned and versioned per model-provider pair, then monitored for regressions before it reaches the pool.

FAQ

Questions, answered.

What is Sand Zen?

A curated pool of eight models, load-tested for coding agents, at transparent list price with 1:1 cache passthrough. No mystery routing, no hidden multipliers.

How is the model list chosen?

Models are scored on agentic coding tasks specifically — tool calls, multi-file edits, long context — not on chat benchmarks. Eight models is deliberate: a small pool can be tuned and monitored, twenty cannot.

What does the cache read price mean?

If a cached prefix is reused, those tokens bill at 0.0318× input on the flagship — about $0.0140 per million. The discount is passed through in full, never absorbed.

Do search and scrape cost extra?

500 search and 500 scrape calls are included every month on Standard, and 2,500 combined on Pro. Beyond that they are billed at $0.02 each.

Can I use these models with other agents?

Yes. The gateway speaks both the OpenAI and Anthropic wire formats, so any client that accepts a custom base URL can use the pool.
